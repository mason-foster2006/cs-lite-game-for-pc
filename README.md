## Project Summary

CS-LITE recreates the essentials of the legendary Counter Strike style of play in a simplified, easy-to-access package. It keeps the familiar tactical shooter structure intact with team-based fights, weapon choices, and map traversal, while running in a browser and relying on standard web technologies.

The aim is to preserve the recognizable Counter Strike feel without demanding powerful hardware or a complicated install process. If you want a lightweight alternative or just a fast way to jump into classic shooter mechanics, CS-LITE offers a direct path into the genre. Ongoing work continues to refine balance and performance.

## Core Features

- Accurate take on Counter Strike gameplay fundamentals and loop
- Team-oriented multiplayer battle scenarios
- Classic weapon and equipment selection
- Objective-driven rounds with map movement and navigation
- Lightweight HTML-based build for wide compatibility
- Ongoing updates focused on stability and feel

## Browser and Platform Support

Built with HTML and JavaScript, CS-LITE works in modern browsers such as Chrome, Firefox, Edge, and Safari. It is intended for PC use and may not behave properly on mobile devices or in older browser releases.
